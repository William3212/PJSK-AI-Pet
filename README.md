# 🐾 PJSK-AI-PET（Unity AI 桌宠）

一个基于 **Unity + Spine + 大语言模型（DeepSeek）** 的桌面 AI 角色系统。  
角色可以与用户自然对话、表现情绪、记忆历史对话，并具备自动总结与长期记忆能力。

> 🎯 本项目目标：打造一个真正“有记忆、有情绪、有性格”的 AI 桌宠。

---

## ✨ 功能特性

### 🤖 AI 对话
- 接入 DeepSeek Chat API
- 支持自然语言对话
- AI 返回 **JSON 格式**，包含：
  - 回复文本
  - 情绪标签（Laugh / Sad / Angry / Surprise / Doubt）

### 🧠 角色独立对话记忆（Chat Memory）
- **每个角色独立保存对话历史**
- 对话上下文自动拼接进请求
- 对话记忆持久化到本地（下次启动仍然存在）
- 支持手动清空当前角色记忆

### 🧩 自动对话总结（记忆压缩）
- 当历史对话过多时自动触发
- 使用 AI 将旧对话总结为一条「对话摘要」
- 保留最近真实对话，防止上下文断裂
- 防止 Token 无限增长
- 不影响正常对话体验

### 🎭 情绪驱动动画系统（Spine）
- AI 情绪 → 对应 Spine 动画
- 支持：
  - Idle / Listen / Talk
  - 情绪动画插入
  - Idle 自动 Joy 表现
- 动画命名规则统一，支持多角色 / 多风格

### 🧍 多角色系统
- ScriptableObject 配置角色
- 支持不同：
  - 骨骼（Spine）
  - 性别
  - 风格
  - 人格 Prompt
- 启动时恢复上一次使用角色

### 🎨 UI 系统
- 角色选择（Dropdown）
- 性别 / 风格切换
- 对话气泡（自动出现 / 消失）
- 输入框
- 设置面板：
  - API URL / API Key
  - 角色 Prompt 编辑
  - 保存到本地
